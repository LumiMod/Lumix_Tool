# S5 对焦音效定制器（Electron 桌面版）

把音频文件（wav/mp3/m4a/flac/ogg）写入 Panasonic DC-S5 的 RAM，并让它成为**对焦提示音**。
修改只发生在内存里，**不写 flash**，不会变砖；电源键重启后仍然有效，拔电池或恢复出厂后消失。

## 运行

1. 确保已安装依赖（只需要一次）：

   ```
   cd app
   npm install
   ```

2. 双击 **`start.bat`**

如果提示找不到 Python 3，点界面右下角「更换」选择 `python.exe`。

## 新手引导（应用内也有）

1. **准备驱动**：用 [Zadig](https://zadig.akeo.ie/) 把相机的 `04DA:2370` 接口绑定为 **WinUSB**（只需一次）
2. **进入服务模式**：关机后按住 `PLAY` + `AF-ON` 再开机，插 USB
3. **确认连接**：点右上角「刷新」，状态变绿「已连接」
4. **选择音频**：拖入文件或点「选择文件」
5. **写入**：点「写入对焦音效」，等待进度完成
6. **热重启试听**：电源键关机再开机（**不要拔电池**），半按快门听对焦音

## 原理（简述）

- 相机服务模式提供只读/只写 RAM 的 USB 命令（`0x5C` 读、`0x9C` 写半字）
- 音效表在 `0x86E35100`，每项 32 字节；ID1 = 对焦提示音
- 自定义 PCM（44100Hz 单声道 s16le）写到空闲区 `0x8F000100`
- 把 ID1 的 `+4`（采样地址）改成 `0x0F000100`、`+0x14`（采样点数）改成写入的采样数
- 播放时相机按表项读取采样，所以能听到自定义声音

## 限制

- 音频上限 3 秒（写入时间约为采样数 × 0.002 秒）
- 拔电池后恢复原厂对焦音
- 只支持服务模式（`04DA:2370`）；正常模式（PTP `04DA:2382`）下无法连接

## 常见问题

| 现象 | 处理 |
|---|---|
| 一直「未连接」 | 确认相机在服务模式；用 Zadig 检查是否绑定了 WinUSB；换一个 USB 口 |
| 点写入没反应/报错 | 看界面底部 Python 路径是否正确；确认相机没有被其它程序占用 |
| 写入成功但听不到变化 | 需要电源键关机再开机（热重启）；确认半按快门触发的是对焦音 |
| 想恢复原厂 | 点「恢复原厂对焦音」，然后热重启；或直接拔电池 |

## 目录

```
app/
├─ start.bat          启动脚本
├─ main.js            主进程（USB 后端调用、文件选择、IPC）
├─ preload.js         安全桥接
├─ renderer.js        界面逻辑（音频解码/重采样/写入进度）
├─ index.html         界面
├─ styles.css         样式
└─ python/
   ├─ s5focus.py      后端（status / apply / restore）
   └─ s5svc.py        服务 USB 客户端（0x5C/0x9C/0x9B）
```
